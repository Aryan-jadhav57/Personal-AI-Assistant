# YOUR AI ASSISTANT 🎯

A simple **Python Tkinter GUI application** that automates searches across popular platforms like **YouTube, Google, and Instagram**. This project demonstrates how to integrate GUI design with web automation using Python’s built‑in libraries.

---

## 🚀 Features
- **YouTube Search** → Enter a query and instantly open YouTube search results.  
- **Google Search** → Automate Google queries directly from the app.  
- **Instagram Lookup** → Enter a username (with or without `@`) to open their profile.  
- **User-Friendly GUI** → Built with Tkinter, featuring a clean steel‑blue background and intuitive buttons.  

---

## 🛠️ Tech Stack
- **Python 3.x**  
- **Tkinter** (GUI framework)  
- **Webbrowser** (to open URLs in default browser)

## ▶️ How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/YOUR_AI_ASSISTANT.git
   ```
2. Navigate to the project folder:
   ```bash
   cd AI_ASSISTANT
   ```
3. Run the script:
   ```bash
   python main.py
   ```
